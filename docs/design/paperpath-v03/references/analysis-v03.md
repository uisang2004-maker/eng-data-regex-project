# PaperPath UI 분석 — v03

## 목적 및 대상
처음 영어 논문을 읽는 학생이 원문을 유지한 채 문제·방법·결과의 3줄 뼈대와 독해 신호를 빠르게 파악하도록 돕는 작업 공간.

## 화면 및 핵심 행동
- 상단 내비게이션: 논문 읽기 / 규칙 탐색 / 검증 결과 (기획서에 명시된 범위)
- 입력: arXiv ID 또는 텍스트 붙여넣기, 초록 불러오기
- 3줄 뼈대: 문제·방법·결과 문장과 신호 문구 및 선택 이유 확인
- 독해: 영어 원문 하이라이트와 한국어 번역을 나란히 읽기
- 근거: 약어 사전 및 규칙 설명 진입점

## v03 디자인 방향
기존 v02 레이아웃과 데이터는 유지하고, Linear/Notion 계열의 절제된 제품 UI에서 영감을 받은 디테일을 추가: 낮은 대비의 유리질 상단 바, 더 조용한 내비게이션 활성 상태, 정교한 표면 그림자, 입력 패널의 얇은 브랜드 액센트, hover 피드백, 간결한 타이포그래피 위계. 특정 서비스 화면이나 로고를 복제하지 않음.

## 상태 및 데이터
현재 화면은 정상 분석 완료 예시 상태. 번역 켜짐. 시연용 논문 데이터이며 실제 논문이 아님을 화면에 표시. 로딩/오류/권한 없음 상태는 원본 자료에서 화면 시안의 필수 범위로 지정하지 않아 추가하지 않음.

## 가정
- v03에서도 1440×900 데스크톱 단일 화면 유지.
- 화면 내 문구와 시연 데이터는 v02 그대로 유지.
- 인터랙션은 CSS hover 수준의 시각 피드백만 추가하며 실제 기능 연결을 주장하지 않음.
