1
Retrieval-augmented generation (RAG) can ground language models in external documents, but selecting reliable evidence remains challenging.
2
To address this issue, we introduce a lightweight reranking module that scores retrieved passages using contextual relevance.
3
Experiments on three public benchmarks show that the proposed module significantly improves retrieval precision by 8.4% compared with the baseline.
4
These findings suggest that a compact reranker may help smaller models use evidence more consistently [4].

01
검색 증강 생성(RAG)은 언어 모델이 외부 문서를 활용하도록 할 수 있지만, 신뢰할 수 있는 근거를 선택하는 일은 여전히 어렵습니다.
02
이 문제를 해결하기 위해, 문맥상 관련성을 사용해 검색된 구절의 점수를 매기는 경량 재순위화 모듈을 소개합니다.
03
세 가지 공개 벤치마크 실험 결과, 제안된 모듈은 기준 모델보다 검색 정밀도를 유의미하게 8.4% 향상시켰습니다.
04
이러한 결과는 소형 재순위화 모델이 더 작은 모델의 근거 활용 일관성을 높이는 데 도움이 될 가능성을 시사합니다 [4].
