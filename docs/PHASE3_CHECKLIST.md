## G. 추가 요청 — 핵심 내용 밑줄 + 카드 번역 (2026-11-04 이의상 요청, 밑줄 설계 검토 3회 후 구현)

정의: **형광펜 = 신호(어떻게 말하나), 밑줄 = 내용(무엇을 말하나).**

- [x] 밑줄은 신호 문구로 찾은 3줄 뼈대 문장에만 긋는다. 위치로 추정한 카드에는 긋지 않고, 배지 툴팁에서 이유를 설명한다(본문에 부정 문구를 띄우지 않음)
- [x] 범위: 신호 뒤에서 시작해 `;`·괄호·`while/whereas`(문제·결과는 `, which/where`도) 앞에서 멈추고 12단어 상한. 방법 문장은 `to`·`that`에서 끊지 않음. 상한에서 잘리면 끝의 기능어(`the`, `with`…)를 뗀다
- [x] 양보절(`Although/Despite X, Y`)은 주어가 시작되는 쉼표 뒤의 주절, 수동태(`is introduced`, `were observed`)는 동사 앞 주어(삽입절 제외). 수동태 신호를 뼈대 규칙에도 추가함
- [x] 신호가 내용 안에 있으면(`... remains challenging`, `outperforms ...`) 그 신호가 든 절
- [x] 번역: 영어 밑줄을 `<u c="u-종류" i="0">`로 바깥에서 감싸 보내고(안쪽 태그를 자르지 않게 경계 확장), 결과에서 가장 긴 조각을 골라 복원. 단어 중간에서 끝나면 단어 끝까지 늘리고(조사 조각은 제외), 끝의 을·를·에서·으로는 밑줄 밖으로 뺀다
- [x] 짝이 맞지 않는 태그는 지워져 번역문에 글자로 남지 않음(테스트)
- [x] 3줄 뼈대 카드 아래에 한국어 번역과 밑줄 표시(번역하기를 누른 뒤)
- [x] 번역 캐시에 DeepL 원본 응답을 함께 저장해, 후처리 규칙이 바뀌어도 다시 호출하지 않고 다시 계산
- 실측(2026-11-04)
  - 샘플 300편: 신호 카드 523개 중 515개에 밑줄. 길이 평균 10.1단어, 16단어 이상 0개(이전 설계는 평균 18.8단어, 57%가 16단어 이상)
  - DeepL: 예시 문단 + 샘플 8편(약 8,300자)에서 한국어 밑줄 12/12, 형광펜 58/58 복원
- 알려진 한계: 문장을 넘는 맥락(다음 문장 `This limits…`)은 잡지 않음. 양보절 주절 안에 쉼표가 많으면 틀릴 수 있음. 상한(12단어)에서 내용이 잘릴 수 있음
