## B. P0별 구현·테스트

2026-11-04 상태: P0 1~6 모두 구현하고 `py -I -m pytest`로 81개 테스트 통과. 실제 외부 호출은 arXiv 1건(1706.03762), DeepL 예시 문단 번역·비교 각 1회로 확인함.


| P0 | 구현 | 테스트 (통과 기준) |
|---|---|---|
| 1 입력 | arXiv ID 불러오기(공식 API, 3초 간격), 최소 방어선(줄바꿈·공백·하이픈·쪽번호 줄·반복 머리말) | 노이즈가 섞인 직접 작성 문단에서 쪽번호·머리말이 지워지고 본문은 유지됨. 잘못된 ID는 오류 안내 |
| 2 3줄 뼈대 | 신호 문구 → 대체(첫 문장 = "분야 배경 (첫 문장)", 마무리 = 공개·미래·윤리 문장을 제외한 수치·결과 동사 문장), 미래·윤리 문장은 한계 카드로, 신호 문구 강조 + 한국어 이유 | 샘플 300건에서 빈 카드 0. 코드 공개 문장이 "결과"로 뽑히지 않음. 채움률을 대체 전후로 기록 |
| 3 약어 | regex 후보 → Python 첫 글자 맞춤 → 대문자로 실패하면 전체 글자로 재시도 | `GRU`·`YOLO`·`LoRA`·`RAG`·`BERT`·`CoT`는 성공. `XGBoost`·`BiLSTM`·`k-NN`은 "정의를 찾지 못함"(틀린 풀네임을 내지 않음) |
| 4 추측·확신 | 단일 "추측·가능성" 등급 + 가능·허용 뜻 제외 목록, 부사·부정어 2개까지 허용 | `may not necessarily reflect` 표시, `may be applied`·`could also be easily extended` 제외 |
| 5 번역 | 버튼을 누를 때만 번역, 비교는 별도 버튼, 문장 캐시, 429·456·네트워크 오류 처리, 개수 안전장치 | 오류를 흉내 낸 상황에서 앱이 멈추지 않고 regex 결과가 유지됨. `len(en) != len(ko)`이면 문단 단위로 표시 |
| 6 근거 규칙 | 하이라이트마다 규칙 이름, 읽기 전용 단계 보기, 준비된 규칙 켜고 끄기(자유 입력 없음) | 추측 제외 규칙을 끄면 `may be applied`가 칠해지고, 다시 켜면 사라짐 |

## C. 5차 검토에서 넘어온 구현 항목

- [x] **C1. 마스킹 시연 자료는 정직하게 고른다.** (2026-11-04 결정: 실측 결과 효과가 작아 비교 버튼은 시연 중심에서 뺌. 수치 보호는 틀린 숫자를 만들어 제거. 상세는 [MASKING_BENCHMARK.md](MASKING_BENCHMARK.md))
  - 2주차 30편 실측에서 실제로 깨진 사례를 시연에 쓴다
  - 직접 만든 어려운 문단을 쓸 때는 화면에 "일부러 만든 어려운 경우"라고 표시하고, 실제 30편 훼손률을 함께 보여 준다
  - 실측 차이가 거의 없으면 비교 버튼을 시연에서 뺀다
- [x] **C2. 문단 단위 번역 + 문장 태그.** (2026-11-04 이의상 결정: 인계서의 문장별 전송보다 우선. 태그가 어긋나면 문장별 전송으로 자동 전환)
  - 문단을 한 번에 보내되 각 문장을 `<s>…</s>`로 감싸고, 결과에서 `<s>(.*?)</s>`로 짝을 복원한다
  - 2026-11-04 실측: 4/4 복원, 대명사 맥락이 회복됨(`them` → "이러한 모델을 위한", `It` → "이 방법은"), 1회 1.23초
  - 테스트: 태그 수가 맞지 않으면 개수 안전장치로 전환한다. 보호 토큰(`<x>`)과 문장 태그가 함께 있어도 복원된다
- [x] **C3. 문제 신호에 대조어를 추가하고, 첫 문장 라벨을 바꾼다.**
  - 추가할 대조어: `but`, `yet`(문장 첫머리), `despite`, `although`, `unfortunately`, `challenging`
  - 실측: 문제 신호가 없는 초록 213건 중 21건이 2~3번째 문장에 대조어가 있음
  - 첫 문장으로 대체할 때의 라벨은 "분야 배경 (첫 문장)" (2026-11-04 이의상 결정: 인계서의 "도입 문장 (배경·문제 추정)"보다 우선)
  - 테스트: "Recent advances … / However, …" 초록에서 문제 카드가 2번째 문장이 됨
- [x] **C4. 수식 보호 패턴을 확장한다.**
  - `\$[^$\n]{1,120}\$`에 더해 `\\\(.+?\\\)`도 문장 분리 전에 보호한다
  - 테스트: `\( x = 1. Y \)`가 들어간 문장이 쪼개지지 않음
- [x] **C5. Streamlit 세션 상태를 고정한다.**
  - `input_text`, `translation_cache`, `active_rules`를 `st.session_state` 키로 고정한다
  - 테스트: `streamlit.testing.v1.AppTest`로 규칙 켜고 끄기·단계 보기 버튼을 눌러도 입력 텍스트와 번역 결과가 유지되는지 확인

- 실측: 소량 시험에서 영어 표시 14개 중 13개가 따라옴. 예시 문단은 6/6. 알려진 한계: 구조가 바뀌는 문장(`may not necessarily reflect`)에서는 태그가 사라지고, 범위가 짧게 잡힐 수 있음(`may` → "수")
