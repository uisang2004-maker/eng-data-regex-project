# 아이디어 2. 레시피 분량·단위 변환기 (Recipe Scaler)

## 한 줄 요약

영어 레시피를 붙여 넣으면, 정규표현식이 **수량(분수·범위·유니코드 분수) + 단위 + 재료**를 뽑아낸다. 그리고 인분 슬라이더와 미국식→미터법 변환 결과를 바로 보여 준다. 덤으로 **1896년 요리책**의 옛 단위가 현대 단위로 얼마인지도 분석한다.

## 대상 데이터와 출처

| 항목 | 내용 |
|---|---|
| 대상 | ① 퍼블릭 도메인 고전 요리책(예: Fannie Merritt Farmer, *The Boston Cooking-School Cook Book*, 1896) ② 사용자가 붙여 넣은 아무 레시피 |
| 출처 | Project Gutenberg |
| 라이선스·약관 | 1896년 출판물은 미국 퍼블릭 도메인이다(Gutenberg 수록). Gutenberg robot access 정책을 2026-11-03에 확인한 결과, 사이트는 사람용이고 자동 도구 접근은 IP 차단 대상이다. 대량으로 받을 때만 wget 규칙과 미러를 허용한다. 따라서 **책 1~2권을 브라우저에서 수동으로 내려받는다** |
| 수집 방법 | 수작업 다운로드(plain text 1~2권). 레시피 수백 개 분량이다 |

## 핵심 regex (2026-11-03 예시 문장으로 실행해 확인)

| # | 패턴(요약) | 잡아내는 것 | 확인 결과 |
|---|---|---|---|
| 1 | `(?P<qty>\d+\s+\d+/\d+\|\d+/\d+\|\d+(?:\.\d+)?(?:\s*[-–]\s*\d+)?\|[¼-¾⅐-⅞])` | **수량**: 대분수, 분수, 소수, 범위(2–3), 유니코드 분수(½) | `1 1/2`, `2-3`, `½`, `1/4` |
| 2 | `(?P<unit>cups?\|tbsps?\.?\|tablespoons?\|tsps?\.?\|teaspoons?\|g\|grams?\|oz\.?\|lbs?\.?\|…)\b\.?` (re.I, re.X) | **단위**와 약어 변형(`tbsp.`, `lb.`) | `cups`, `tbsp`, `teaspoon`, `g`, `lb` |
| 3 | 1+2 뒤에 `\s+(?:of\s+)?(?P<item>[a-z]+)` | **재료명** | `flour`, `butter`, `salt`, `sugar`, `bacon` |
| 4 | `(?P<deg>\d{2,3})\s*°\s*(?P<scale>[FC])\b` | **오븐 온도**. °F↔°C로 바꾼다 | `350°F` |
| 5 | `(?P<n>\d+)\s*(?P<u>minutes?\|mins?\|hours?\|hrs?)\b` (re.I) | **조리 시간**. 타임라인 시각화에 쓴다 | `25 minutes` |

- 일부러 놓치는 경우: `a pinch of nutmeg`처럼 숫자가 없는 표현. 실제로 놓치는 것을 확인했고, 이런 표현은 "변환 불가"로 따로 표시한다
- 고전 요리책 특유의 표현(`butter the size of an egg`, `a gill`, `a teacup`)은 2차 패턴으로 잡아 "옛 단위 사전"을 만든다

## 파이프라인

1. **collect**: Gutenberg plain text를 `data/raw/`에 둔다
2. **clean**(regex): Gutenberg 머리말과 꼬리말을 자르고(`\*\*\* START OF .*? \*\*\*`), 레시피 단위로 나눈다(대문자 제목 줄 `^[A-Z][A-Z ,'-]+$`)
3. **extract**(regex): 재료 줄 → (수량, 단위, 재료), 온도, 시간
4. **analyze**: 분수를 `fractions.Fraction`으로 바꾸고, 인분을 조정하고, 단위를 환산한다. 책 전체의 단위 빈도와 옛 단위 출현 횟수를 센다
5. **visualize**: 하이라이트된 레시피, 변환 표, 1896년 단위 빈도 차트

## 결과 화면 묘사

레시피를 붙여 넣으면 수량은 파랑, 단위는 초록, 재료는 노랑으로 칠해진다. 오른쪽 표는 "1 1/2 cups flour → 3 cups / 360 ml"처럼 바뀌고, **인분 슬라이더**를 움직이면 숫자가 실시간으로 다시 계산된다. 탭을 바꾸면 "1896년 요리책에서 가장 많이 쓰인 단위 Top 10"과 "teacup, gill은 지금으로 몇 ml?" 차트가 나온다.

## 판단 기준 점수

| 기준 | 점수 | 근거 |
|---|---|---|
| regex 중심성 | 5 | 수량, 단위, 재료를 파싱하지 못하면 변환이 성립하지 않는다 |
| 시연 임팩트 | 4 | 슬라이더로 숫자가 바뀌는 모습은 직관적이다. 다만 "실용 앱" 느낌이라 놀라움은 1번보다 약하다 |
| 데이터 실현성 | 5 | 퍼블릭 도메인이고 수동 다운로드 한 번이면 끝이다 |

| 범위 적합성 | 4 | 핵심은 작다. 다만 옛 요리책 형식이 지저분해 레시피 분할에 시간이 들 수 있다 |
| **합계** | **22** | |

## 예상 위험

- 고전 요리책의 재료 줄은 서술형("Mix two cups of flour with…")이 많다. 영어 수사(`two`, `half`)를 처리하는 패턴이 추가로 필요하다
- 단위 환산은 부피와 무게가 섞여 있어 재료별 밀도가 필요하다. 범위는 부피↔부피, 무게↔무게로 제한한다
