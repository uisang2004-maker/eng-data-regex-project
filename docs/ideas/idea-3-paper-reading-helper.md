# 아이디어 3. 논문 약어 X-ray (Paper Acronym X-ray)

## 한 줄 요약

arXiv 논문 초록에서 정규표현식으로 **"풀네임 (약어)" 정의**와 **수치 주장(%, p-value)**을 뽑는다. 이것으로 분야별 약어 사전을 만들고 "AI 논문 약어 인플레이션" 추이를 보여 준다.

## 대상 데이터와 출처

| 항목 | 내용 |
|---|---|
| 대상 | arXiv cs.CL / cs.LG 등 분야의 초록 수천 건(연도별) |
| 출처 | arXiv API (export.arxiv.org) |
| 라이선스·약관 | arXiv API 이용약관을 2026-11-03에 확인한 결과, 제목·초록·저자 같은 **메타데이터는 CC0 1.0**이다. 요청은 **3초에 1회, 연결 1개**로 제한된다. 저자 이름은 개인정보에 가까우므로 수집 필드에서 뺀다 |
| 수집 방법 | 공식 API(무료·키 없음). 3초 간격으로 페이지당 100건씩 요청한다 |

## 핵심 regex (2026-11-03 예시 문장으로 실행해 확인)

| # | 패턴 | 잡아내는 것 | 확인 결과 |
|---|---|---|---|
| 1 | `\((?P<abbr>[A-Z][A-Za-z]*[A-Z]s?)\)` | 괄호 속 **약어 후보**(복수형 `LLMs` 포함) | `NLP`, `LLMs`, `RLHF` |
| 2 | 약어 글자 순서로 앞 단어의 첫 글자를 맞춘다(연결어 `of/from/and` 허용). 정규식 + 짧은 Python 로직 | **약어 → 풀네임** | `NLP → Natural Language Processing`, `RLHF → Reinforcement Learning from Human Feedback` |
| 3 | `(?P<num>\d+(?:\.\d+)?)\s*%\|\bp\s*[<=>]\s*0?\.\d+` | **수치 주장**(향상 폭, 유의확률) | `4.2%`, `p < 0.05` |
| 4 | `\b(?:outperform\|surpass\|state[- ]of[- ]the[- ]art\|SOTA)\w*\b` (re.I) | **성능 과시 표현**. 연도별 증가 추이를 본다 | (프로토타입에서 확인 예정, 미실행) |

- 일부러 놓치는 경우: 첫 글자 규칙을 따르지 않는 약어(`XGBoost`, `BERT`의 원래 풀네임처럼 정의 없이 쓰는 경우)

## 파이프라인

1. **collect**: arXiv API → `data/raw/arxiv_<cat>_<year>.jsonl`
2. **clean**(regex): LaTeX 수식(`\$[^$]+\$`)과 줄바꿈 하이픈을 지우고 공백을 정규화한다
3. **extract**(regex): 약어 정의, 수치, 과시 표현
4. **analyze**: 연도별 초록당 약어 수, 새로 등장한 약어, 같은 약어의 다른 풀네임(동음이의 약어, 예: `RL`)을 센다
5. **visualize**: 약어 사전 검색, 연도별 추이 선그래프, 동음이의 약어 네트워크

## 결과 화면 묘사

초록을 붙여 넣으면 약어 위에 풀네임 툴팁이 달리고 수치 주장이 표시된다. 아래에는 "cs.CL 초록 1편당 약어 수: 2015년 1.1개 → 2025년 ?개" 선그래프가 있다(값은 수집 후 확정). 검색창에 `RL`을 치면 그 약어가 뜻하는 풀네임들이 나온다.

| 기준 | 점수 | 근거 |

| 시연 임팩트 | 3 | 논문에 익숙하지 않은 동료에게는 와닿기 어렵다. 직접 입력해 보기도 덜 재미있다 |

| 차별성 | 4 | 약어 추출 자체는 학계에 있는 주제지만, 수강생 주제와 겹칠 가능성은 낮다 |
| 범위 적합성 | 4 | 수집 속도 제한(3초/회) 때문에 대량 수집에 몇 시간이 걸린다. 미리 받아 두면 된다 |
